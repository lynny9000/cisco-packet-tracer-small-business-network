# Cisco Networking Labs

A structured Cisco Packet Tracer networking project covering switching, VLANs, routing, wireless integration, redundancy and basic network security within a simulated small business environment.

---

# Features

* VLAN creation and segmentation
* Inter-VLAN routing using router-on-a-stick
* NAT and Internet edge configuration
* Static routing and routing table analysis
* 802.1Q trunking and native VLAN configuration
* STP redundancy and loop prevention
* Root bridge and PortFast configuration
* Multi-site OSPF dynamic routing
* Wireless access point integration
* WPA2 wireless security
* ACL-based traffic filtering and network protection
* WAN and branch office simulation

---

# How it Works

The project uses Cisco Packet Tracer to simulate a realistic SMB/enterprise-style network environment using Cisco routers, switches, VLANs, routing protocols and wireless infrastructure.

Each lab builds progressively on the previous one, gradually expanding the network from a basic VLAN topology into a multi-site routed infrastructure with wireless access and security controls.

The labs are designed to demonstrate practical networking concepts using Cisco IOS CLI configuration and verification commands.

---

# Network Topology

The final topology contains the following components:

* Internet edge simulation
* ISP router
* HQ router and switching infrastructure
* Branch office WAN router
* Branch office LAN
* Department VLANs
* Wireless access point and wireless client
* Redundant switch uplinks
* OSPF site-to-site routing
